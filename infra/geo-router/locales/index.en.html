What are lightweight static web games?

“Lightweight static web games” are browser games that need no server, no database and no build tooling. They consist of static files (HTML, CSS, JavaScript) that the browser parses and runs directly, and they can be deployed to any static host — GitHub Pages, Gitee Pages, Netlify, Vercel and so on.

This project focuses on three things:

  • Performance: zero third-party dependencies and a first-payload below 50 KB, so pages open in an instant.
  • Accessibility: semantic elements, full keyboard support, ARIA labelling and respect for the “reduce motion” preference.
  • Indexability: complete meta tags, Open Graph, Twitter Card and JSON-LD structured data, so search engines and generative engines (AI summaries and citations) can understand the page.

Do I need a connection or an installation to play?
No. The site is built from pure HTML, CSS and vanilla JavaScript with zero third-party dependencies and runs directly in the browser.
Which games are available?
Four casual games: slots, dice higher-or-lower, coin flip and 21-point blackjack. All of them share one virtual-chip balance stored locally in your browser.
Why is the site built as a static site?
A static architecture stays small, loads instantly, costs little and is easy to deploy anywhere, while semantic markup helps search engines and AI systems crawl, summarise and cite it.
How are virtual chips and the balance stored?
The balance lives in your browser's local storage (localStorage). It never leaves your device and is never uploaded to a server; clearing browser data or switching devices resets it, and you can start over at any time.
Do the games make network requests or upload my data?
No. All game logic and data storage happen locally in the browser — no backend, no accounts and no outbound requests, so your privacy is protected by design.
How does the site encourage sensible play?
Only virtual chips are used and no real money is involved. Set yourself a time limit, keep it moderate, and always treat the site as a technical demonstration and casual entertainment — never as real gambling.
